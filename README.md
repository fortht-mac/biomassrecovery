# biomassrecovery

<!-- badges: start -->

<!-- badges: end -->

The goal of biomassrecovery is to present a simple package that
exemplifies some simple R functions and reports biomass recovery
trajectories for tropical forests at the ecoregion scale.

The package was created with {usethis} functions and has been documented
and populated appropriately.

## Installation

You can install the development version of biomassrecovery like so:

``` r
#install.packages("pak")
pak::pkg_install("fortht-mac/biomassrecovery")
```

Afterwards, to load the package, type:

``` r
library(biomassrecovery)
```
